Arcana Press —— 本地运行说明
================================

Windows
-------
双击 START.bat

它会自动完成：找 Python → 建虚拟环境 → 装依赖 → 生成配置和随机密钥
→ 种入 3 位示例读牌师和几笔订单 → 启动服务 → 打开浏览器。

浏览器会自动打开 http://localhost:5000
关闭服务：在黑窗口里按 Ctrl+C

要求：Python 3.9 以上。没装的话去 https://www.python.org/downloads/
安装时务必勾选 "Add python.exe to PATH"。


Mac / Linux
-----------
./dev.sh


从 git 拉代码？
--------------
用 tarot-fromgit.py：放到你想安装的位置，运行它。
它会浅克隆仓库，把 tarot/ 子目录提上来，删掉克隆，然后直接启动。
重复运行 = 拉最新代码；你的 .env 和数据库不会被动。
需要先装 git：https://git-scm.com/download/win

手动 git 命令（代码会在 tarot-repo\tarot 里，多一层）：

    cd /d D:\website
    git clone --depth 1 -b <分支名> <仓库地址> tarot-repo
    cd tarot-repo\tarot
    START.bat


只有 tarot-setup.py 一个文件？
------------------------------
那个文件把整个项目装在自己肚子里。把它放到你想安装的位置，然后：

    Windows    双击它，或在命令行运行  py -3 tarot-setup.py
    Mac/Linux  python3 tarot-setup.py

它会在自己旁边写出 tarot 文件夹（如果它本来就在名为 tarot 的文件夹里，
就直接装在原地），然后建环境、装依赖、种数据、启动、开浏览器。
不需要解压，所以不会再出现"文件夹是空的"。


跑起来之后看哪些页面
--------------------
/                      首页
/reading/celtic-cross  抽十张牌，解读逐段浮现
/report                填写处境，生成完整报告
/cards                 78 张原创牌面
/readers               向真人读牌师下单
/desk                  读牌师工作台（密钥启动时会打印）
/admin                 运营台（密钥启动时会打印）
/legal/privacy         红色 MISSING 标记 = 还需要补的注册信息

右上角 Theme 按钮可切换深色/浅色。


重复运行是安全的
----------------
已经存在的 .env、数据库、你改过的代码都不会被覆盖。
